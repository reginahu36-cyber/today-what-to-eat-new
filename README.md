# 今天吃什麼｜V69 新專案

本專案以「今天吃什麼」V69 原始 HTML 為基礎，保留既有粉色療癒風格及其他功能，並在最終相容層停用「地雷美食」分類與相關介面。

## 專案內容
- `index.html`：完整、自包含的網站主程式（樣式與主要程式碼內嵌，不需另外安裝套件）。
- `manifest.json`：可選的網頁應用程式資訊，供支援的瀏覽器使用。
- `icons/`：網站圖示。
- `README.md`：部署說明。

## 在 GitHub Pages 發布
1. 在 GitHub 建立新的 Repository。
2. 將本資料夾內的所有檔案與 `icons` 資料夾上傳到 Repository 根目錄（不要只上傳 ZIP）。
3. 進入 **Settings → Pages**。
4. 在 Build and deployment 選擇 **Deploy from a branch**，分支選 `main`，資料夾選 `/(root)`，按 Save。
5. 等待 GitHub Pages 完成部署後，使用 Pages 顯示的新網址開啟網站。

## 注意
- 這是獨立的靜態網站包，不會自行修改任何既有 Repository 或網站。
- 資料儲存方式沿用 V69 的瀏覽器端儲存機制；不同瀏覽器／裝置之間不會自動雲端同步。清除網站資料可能會移除本機資料，建議定期使用網站內的備份功能。
